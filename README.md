# نظام إدارة الموارد البشرية والمستندات

نظام متكامل مصمم بلغة Python لإدارة شؤون الموظفين وإصدار المستندات المختلفة للموظفين في المؤسسات والإدارات العمومية في الجزائر.

## الميزات الرئيسية

- إدارة قاعدة بيانات الموظفين
- إنشاء المستندات الرسمية التالية:
  - شهادات العمل
  - كشوف الرواتب
  - أذونات الإجازات (سنوية، مرضية، أمومة)
  - أوامر المهام
  - وثائق الترقية (في الدرجة والرتبة)
  - تقارير الحضور اليومي
  - بطاقات الموظفين
  - شهادات الخبرة المهنية
  - تصاريح مباشرة/عدم مباشرة العمل
  - شهادات استئناف العمل
- واجهة مستخدم سهلة الاستخدام باللغة العربية
- نظام بحث وتصفية متقدم
- إدارة المستخدمين والصلاحيات

## متطلبات النظام

- Python 3.8 أو أحدث
- قاعدة بيانات SQL (SQLite للتطوير، PostgreSQL للإنتاج)
- مكتبات Python (مذكورة في ملف requirements.txt)

## التثبيت

### 1. استنساخ المستودع

```bash
git clone https://github.com/your-username/hr-management-system.git
cd hr-management-system
```

### 2. إنشاء بيئة Python افتراضية

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# أو
.venv\Scripts\activate  # Windows
```

### 3. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 4. تثبيت الخطوط العربية

قم بتنزيل ملفات الخطوط العربية (مثل Arial.ttf، Arial_Bold.ttf) ووضعها في مجلد `static/fonts`.

### 5. إعداد قاعدة البيانات

لأغراض التطوير، سيتم إنشاء قاعدة بيانات SQLite تلقائياً. للإنتاج، قم بتعديل متغير البيئة `DATABASE_URL` ليشير إلى قاعدة بيانات PostgreSQL الخاصة بك.

### 6. تشغيل التطبيق

```bash
python main.py
```

سيتم تشغيل التطبيق على المنفذ 5000. يمكنك الوصول إليه عبر المتصفح على العنوان `http://localhost:5000`.

## إنشاء مستخدم أول مرة

1. افتح المتصفح واذهب إلى `http://localhost:5000/register`.
2. قم بإنشاء حساب مستخدم جديد.
3. بعد إنشاء الحساب، قم بتعديل قاعدة البيانات مباشرة لجعل المستخدم مديراً:

```sql
UPDATE user SET is_admin = 1 WHERE id = 1;
```

## استخدام النظام

### إدارة الموظفين

1. أضف الموظفين الجدد من خلال الضغط على "إضافة موظف جديد" في لوحة التحكم أو من قائمة الموظفين.
2. قم بتعبئة بيانات الموظف الشخصية، بيانات العمل، ومعلومات الاتصال.
3. يمكنك عرض وتعديل وتعطيل حسابات الموظفين من خلال قائمة الموظفين.

### إنشاء المستندات

1. انتقل إلى صفحة "إنشاء مستند جديد" من لوحة التحكم أو قائمة المستندات.
2. اختر نوع المستند المطلوب إنشاؤه.
3. حدد الموظف المعني بالمستند.
4. أدخل البيانات المطلوبة حسب نوع المستند (ستظهر حقول مختلفة حسب النوع المختار).
5. اضغط على "إنشاء المستند" لتوليد المستند بتنسيق PDF.
6. يمكنك عرض، تنزيل، أو إعادة إنشاء المستندات من صفحة تفاصيل المستند.

## تخصيص النظام

### تخصيص قوالب المستندات

يمكنك تعديل مظهر المستندات المُنشأة من خلال تعديل الدوال الموجودة في ملف `utils/pdf_generator.py`.

### تخصيص الواجهة

قوالب الواجهة موجودة في مجلد `templates`. يمكنك تعديلها حسب الحاجة لتغيير مظهر التطبيق.
